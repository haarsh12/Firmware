# GharSathi Home Guide

## Devices

- Relay 1 is the room light.
- Relay 2 is the room fan.
- The relay board must be connected before a command can physically operate a device.

## Command rules

- "Light on", "batti chalu karo", and "light chalu karo" mean turn the light on.
- "Light off", "batti band karo", and "light band karo" mean turn the light off.
- "Fan on", "pankha chalu karo" mean turn the fan on.
- "Fan off", "pankha band karo" mean turn the fan off.
- If the user asks only for status, read status; do not change a relay.
- If a request does not name light or fan, ask which device the user means.

## Safety and honesty

- Confirm a physical operation only after the device-control tool confirms it.
- If the relay board is disconnected, explain that the command could not be delivered.
- Never claim a sensor reading or a physical action without a tool result.
